## 📝 Обновление документации

### Когда обновлять:

- **README.md** — При добавлении функций, изменении API
- **QUICK_START.md** — При изменении процесса установки
- **INSTALLATION.md** — При новых проблемах или решениях
- **PRE_RELEASE_CHECKLIST.md** — При новых требованиях к релизу
- **bl_info_example.py** — При изменении структуры __init__.py
- **package_addon.py** — При изменении структуры проекта

### Как обновлять:

1. Внесите изменения в соответствующий файл
2. Обновите дату/версию в конце файла
3. Проверьте ссылки на другие документы
4. Обновите этот индекс, если добавлены новые файлы
